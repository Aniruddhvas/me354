# ME 354 Mechanics Lab

Interactive tools for ME 354 Mechanics of Materials at the University of Washington (Prof. Aniruddh Vashisth).

**Live site:** https://aniruddhvas.github.io/me354/

The modules follow the ME 354 course notes by Prof. Lucas R. Meza. The site was inspired by Prof. Navid Zobeiry's [UW Composites Analysis](https://composites.uw.edu/analysis/) tools. Everything runs in the browser from a single `index.html`, with no build step.

Embed one module on another page (e.g. Google Sites) with `#embed-<module>`, for example `https://aniruddhvas.github.io/me354/#embed-mohr`.
